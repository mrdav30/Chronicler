Exact simulation timestamps, signed durations, and an explicitly advanced
<xref:Chronicler.Timing.ChronicleClock>. The host owns the simulation origin,
advancement, and reset/restore lifetime.

Use <xref:Chronicler.RecordChronicleTime> to record time values through the
shared schema. See [Simulation timing](../guides/simulation-timing.md) for
arithmetic, frame deadlines, and restore examples.
